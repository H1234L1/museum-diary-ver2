# 人生博物馆 · Life Museum 🏛️



> 收藏人生中的每一个重要瞬间，让平凡的日子成为独一无二的展品。



人生博物馆是一款基于微信小程序的个人记忆收藏应用。  

我们希望帮助用户将日常生活中的照片、文字、语音等碎片化记录，转化为属于自己的数字展品，并构建一座只属于自己的虚拟人生博物馆。



每一次记录，都是一次入藏；

每一个瞬间，都是一件展品。



---



## ✨ 项目介绍



现代人的生活充满了大量瞬间：



- 一张随手拍下的天空

- 一次重要的旅行

- 一段成长中的感悟

- 一件陪伴多年的物品



但这些记忆往往散落在相册、聊天记录和备忘录中，很难被重新发现。



**人生博物馆希望改变这种记录方式：**



从：



> "我保存了一张照片"



变成：



> "我收藏了一件属于自己的人生展品"



用户可以通过文字、图片、语音等形式记录生活，并在 AI 的辅助下生成具有博物馆感的展品信息，最终形成个人专属的虚拟博物馆。



---



# 🎨 核心功能



## 1. 📦 人生展品收藏



用户可以创建自己的展品：



- 图片记录

- 文字记录

- 语音记录



每件展品都会拥有：



- 展品编号

- 收藏时间

- 展品名称

- 展品描述

- 展示信息



例如：



```

No.0001



名称：

十八岁的夏天



时间：

2026.08.01



描述：

这是我第一次参加互联网实践，

也是第一次认真思考未来方向的夏天。

```



---



## 2. 🏛️ 个人博物馆空间



所有展品会被收藏到用户自己的博物馆中。



用户可以：



- 创建不同主题展厅

- 管理展品分类

- 查看自己的收藏轨迹



例如：



```

我的人生博物馆



├── 高中时代

│   ├── 毕业旅行

│   └── 最后一场考试

│

├── 十八岁

│   ├── 腾讯实践

│   └── 第一次科研尝试

│

└── 我的收藏

```



---



## 3. 📖 沉浸式展品展示



不同于传统的信息列表展示方式，我们希望模拟真实博物馆体验。



展品页面包含：



- 墙面展示空间

- 展品画框

- 展牌信息

- 展示灯光效果



让用户不是简单查看数据，而是在"参观自己的人生"。



---



## 4. 📊 人生月报



系统会根据用户记录生成个人回顾：



包括：



- 当月收藏字数

- 累计入馆时间

- 当月收藏图片数量

- 入馆天数

- 最喜爱的展厅

- 最晚离馆时间



帮助用户发现：



> 原来这个月，我留下了这么多值得收藏的瞬间。

# 🎯 项目愿景



我们相信：



> 人生不是由几个重大事件组成，而是由无数被记住的小瞬间组成。



人生博物馆希望成为每个人自己的时间胶囊。



未来，当用户再次打开这座博物馆时，

看到的不只是照片和文字，



而是一段被认真收藏的人生。
